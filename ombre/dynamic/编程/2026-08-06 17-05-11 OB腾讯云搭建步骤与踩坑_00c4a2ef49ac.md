OB迁移腾讯云搭建过程：1.git clone仓库 2.装Docker（curl -fsSL https://get.docker.com | sudo sh）3.docker build -t ombre-brain . 4.用echo命令逐行创建.env文件（echo 'KEY=VALUE' > .env 第一条用单箭头，后续用>>双箭头）5.sudo docker run -d --name ombre-brain --env-file .env -p 8000:8000 -v /app/buckets:/app/buckets --restart unless-stopped ombre-brain 6.防火墙开8000端口（TCP，来源0.0.0.0/0）。遇到的问题：Docker没装（选的纯Ubuntu不是Docker模板）、permission denied（加sudo或usermod -aG docker）、nano编辑器误入（Ctrl+X退出）、关掉终端页面后重新登录继续。环境变量注意：OB实际要的是OMBRE_DASHBOARD_PASSWORD不是DASHBOARD_PASSWORD，变量名写错会导致无法设置密码。看日志命令：sudo docker logs ombre-brain。
