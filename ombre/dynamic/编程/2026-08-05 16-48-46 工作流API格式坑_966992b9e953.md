工作流关键坑：workflow_get返回旧格式（nodeId/toolName/modelId/systemPrompt），workflow_update_graph需要新格式（node_index索引引用、tool、model_id、system_prompt、op用kind）。ref引用用node_index数字，不是nodeId字符串。

橘子岛工作流API关键坑（2026年8月6日踩坑总结）：1.workflow_get返回旧格式（nodeId/toolName/modelId/systemPrompt），workflow_update_graph需要新格式（node_index/tool/model_id/system_prompt/op用kind）。2.API创建/更新工作流后触发器格式会被系统存错（cronlike+intervalMs或interval+expr），导致调度器注册失败。解决办法：创建后在UI上手动选触发器类型。3.API update工作流会生成新节点ID，但调度器缓存旧ID，导致No matching start node。解决办法：不要update，要改就删了重建。4.workflow_create_graph的transform节点op必须用kind字段指定类型（regex/jsonpath/join），不能用type。
