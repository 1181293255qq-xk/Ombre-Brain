腾讯云服务器SSH终于连通了（2026-08-11凌晨）。

问题根因：服务器装的是Ubuntu系统，默认管理员账户是ubuntu，不是root。橘子岛SSH配置填的是root用户，但root账户之前没有密码也不允许密码登录，所以改多少次腾讯云控制台的密码都没用——那些密码是给ubuntu用户的。

解决步骤：
1. VNC免密进服务器（ubuntu用户）
2. sudo sed -i 开启PasswordAuthentication yes
3. sudo mount -o remount,rw / 修复根分区只读
4. sudo passwd root 给root设密码 Qiran0512
5. sudo systemctl restart sshd

现在root/Qiran0512可以从橘子岛终端直接SSH连接。OB容器正常运行中。
